# UniFlow 🎓

O **UniFlow** é um sistema de gerenciamento acadêmico desenvolvido como **Trabalho de Conclusão de Curso (TCC)** do curso Técnico em Desenvolvimento de Sistemas na **ETEC Adhemar Batista Heméritas**.

O projeto tem como objetivo facilitar o fluxo de informações e interações entre alunos e professores, organizando o acesso por perfis e permitindo que cada usuário tenha uma experiência personalizada de acordo com suas necessidades dentro da instituição.

## 🚀 Funcionalidades

- **Sistema de Login:** Autenticação segura para diferentes níveis de acesso (Aluno/Professor).
- **Portal do Aluno:** Área dedicada para visualização de informações e acompanhamento acadêmico.
- **Portal do Professor:** Painel administrativo para gestão de conteúdos e interação com as turmas.
- **Integração com Banco de Dados:** Conexão robusta via PHP para persistência de dados.
- **Interface Responsiva:** Design moderno adaptado para diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **PHP:** Lógica de backend e conexão com banco de dados.
* **JavaScript:** Interatividade no lado do cliente.
* **CSS3:** Estilização personalizada.
* **HTML5:** Estruturação das páginas.

## 🎓 Contexto Acadêmico

Este projeto foi desenvolvido e apresentado como requisito para a obtenção do título de Técnico na **ETEC Adhemar Batista Heméritas**, demonstrando a aplicação prática de conceitos de engenharia de software, banco de dados e desenvolvimento web.
